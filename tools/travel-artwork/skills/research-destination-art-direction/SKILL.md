# Research destination art direction

Read [house standard](references/house-style.md) and use [brief form](references/destination-brief.md). This skill produces a sourced creative brief; it does not implement a frontend or authorize spending.

Establish destination, intended placements, season and supplied accepted references. Ask one focused question only if a missing choice materially changes the research. If no destination was supplied, ask which destination to start with; do not silently choose Japan or Singapore.

Research distinctive architecture, landscapes, materials, light and graphic traditions using credible sources. Include everyday details alongside major landmarks. Separate observable facts from interpretation, and attach URLs/retrieval dates. Record reference rights and research/inspiration/upload use. If browsing is unavailable, label observations provisional; do not fabricate citations.

Propose two or three materially different directions with subject, art technique, composition and 4–6 candidate color roles. Derive palettes from the destination and brief. The user's example shades are not defaults or required colors. Explain trade-offs across a postcard, hero and readable planning panel. A contrast ratio may be reported only from an executed deterministic calculation with its output available. If no such tool was run, mark contrast unverified; never invent a computed ratio in prose.

Present your recommendation with the brief in `proposed` state. Capture the user's actual selection before changing it to selected. End with the next action and missing evidence. Read [handoff contract](references/asset-contract.md) when preparing production jobs. Provide a Flow-ready handoff; claim tool integration only after it is actually exercised.

Example request: "Research a Copenhagen autumn pack for a premium postcard travel interface; compare print illustration and observational photography." Output: evidence table, two distinct directions, cross-placement assessment, recommendation and a proposed brief awaiting selection.
