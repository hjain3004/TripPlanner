Gazette · four masthead treatments · newsprint ground

A gazette is a layout system, not a typeface — nameplate, double rule, dateline, condensed deck, ruled columns. Each treatment below is the complete system, so the face is judged inside the structure it has to live in. Geometry is Direction A's, unchanged: hard border, offset plate, mono metadata, tabular figures.
